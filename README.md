### ❯ whoami

Student and systems tinkerer. I take bare Linux boxes and make them fast, hardened
and observable — kernel tuning, nftables, containers, tunnels — then turn the scars
into scripts and runbooks. Off the servers I study electronics design: PCBs, STM32,
circuit simulation. Most of it is pair-built with **Claude Code**, hence
*“doctore claude”* — I set the task, verify the result and answer for it myself.

- 🌐 [**jestivald.tech**](https://jestivald.tech) — terminal-flavored homepage
- 💬 [**@jestivald**](https://t.me/jestivald) — Telegram

### ❯ ls ~/projects

| repo | what it does |
|------|--------------|

| [**server-bench**](https://github.com/jestivald/server-bench) | All-in-one server diagnostics & benchmark — CPU/disk/net, scorecard verdicts, `--json` output |

### ❯ ls ~/work

Things that live outside GitHub:

| project | what it does |
|---------|--------------|
| [**vneplena.com**](https://vneplena.com) | VPN service — node fleet, Telegram bot and web account |
| **fleet monitoring** | VictoriaMetrics + Grafana for 43 hosts — 14 dashboards, 183 alert rules, passkey sign-in |
| **infra-billing** | FastAPI + SQLite app that tracks servers, leases and payments, syncs with the provider daily and sends payment reminders to Telegram |

| **home-win-mcp** | MCP server for my home Windows PC, so an AI agent can drive Multisim and KOMPAS-3D from any laptop |
| **retail point of sale** | Client work — a POS app for a retail chain with receipt printing and 1C sync |
